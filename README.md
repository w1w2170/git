# git

这是一个通过 Git 推送到 GitHub 的测试仓库。

- 本地路径：`C:\Users\23355\Desktop\新建文件夹`
- 远程地址：<https://github.com/w1w2170/git.git>
- 默认分支：`main`

## 常用命令

```bash
git status              # 查看改动
git add .               # 暂存全部改动
git commit -m "说明"    # 提交
git push                # 推送到远程
git pull                # 拉取远程更新
```
